# 示例个性化配置（完全虚构）

> 仅用于展示怎么填。该示例为人工构造，不对应任何真实用户、学校、项目或未公开研究。

## 阶段

管理学硕士二年级。

## 当前研究

主题：
混合办公情境下团队沟通模式与知识共享行为。

核心链条：
混合办公安排 → 沟通结构与媒介使用 → 知识共享行为 → 团队协作结果。

冻结边界：
不临时增加新的组织层级样本，不因单篇新论文更换主要结果变量，不把相关关系解释为因果效应。

只有以下证据出现时复核：
- 当前核心量表的测量效度存在直接问题；
- 新研究显示当前分析层级与数据结构明显不匹配；
- 现有设计对关键混杂因素存在无法忽略的系统性遗漏。

## 成果池

A：混合办公条件下的沟通结构与知识共享。
B：数字协作工具使用与团队协作结果。
