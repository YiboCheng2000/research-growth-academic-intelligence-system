# v1.0.0 — First Public Release

`Research Growth & Academic Intelligence System` is a reusable workflow for researchers who want more than a stream of paper recommendations.

## What it does

It organizes recurring research support into three modes:

- **Method & capability development** — learn one durable research/data/AI skill at a time.
- **Research & publication deep reading** — dissect one paper around the question: why can this study stand as an independent paper?
- **Academic intelligence** — monitor recent research, source ecosystems, calls, conferences, counter-evidence, and adjacent fields.

## Core mechanisms

The first release includes:

- Candidate Discovery
- Perspective Expansion
- DOI/title/author-year deduplication
- Personalized relevance screening
- Discovery-source vs evidence-source separation
- Evidence access labels
- Claim–Evidence Gate
- Contradiction Search
- Literature-level and knowledge-level novelty checks
- Contribution Mapping
- Information-bubble audit
- User-feedback calibration
- Gate-6 real-use audit after 2–4 weeks

## Privacy and scope

This public release is deliberately sanitized. It contains no private profile, private email address, unpublished user-specific research plan, participant data, account-specific task ID, or credential.

The workflow is **not** a systematic-review protocol by default and does not guarantee complete database coverage. Researchers remain responsible for source verification and scholarly judgment.

## Platform use

The repository includes a ChatGPT Scheduled Task template, a generic cross-platform adaptation guide, and a portable `skill/` starter structure. Scheduling, connected-app actions, Skill availability, and installation behavior vary by product, plan, workspace, and permissions.
