# Security and privacy reporting

This repository should not contain production credentials or private research data.

If you discover an accidentally committed secret, private email address, participant information, private file link, account-specific identifier, or other sensitive information:

1. Do not repost the sensitive value in a public issue.
2. Contact the repository maintainer through a private channel configured for the repository, or use GitHub's private vulnerability reporting feature if the maintainer enables it.
3. If the value is a credential or API key, assume exposure and rotate/revoke it immediately.
4. Removing a secret from the latest commit is not sufficient if it exists in Git history.

For normal documentation errors, use public issues.
