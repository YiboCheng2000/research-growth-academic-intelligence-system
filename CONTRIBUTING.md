# Contributing

Contributions are welcome, especially reports based on real use over multiple weeks.

Useful contributions include:

- a source that is consistently inaccessible or misclassified;
- an example where an abstract was treated as full-text evidence;
- duplicated knowledge that survived the novelty gate;
- false-positive or false-negative contradiction search behavior;
- a better personalization field;
- an adaptation pattern for another AI platform;
- a product-capability statement that has become outdated.

## Before opening an issue or pull request

1. Remove private email addresses, credentials, unpublished data, participant information, private repository links, and account-specific task IDs.
2. Distinguish observed behavior from assumptions about how an AI product works internally.
3. Link to an original source when proposing a factual product or research-source change.
4. For product-capability changes, prefer current official documentation.
5. Do not paste copyrighted full papers or paywalled text into issues.

## Pull requests

Keep changes small and explain:

- the problem;
- the proposed change;
- the evidence;
- whether it changes the core workflow;
- whether a new Gate-6 audit is needed.
